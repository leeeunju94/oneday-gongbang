# 사이트 설계도(PRD) — (미정: 공방 이름)

작성일: 2026-11-18 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
친구·동료 모임이 함께 즐기는 원데이 클래스 공방.

## 2. 손님
- 누가: 친구·동료 모임 (함께 체험할 거리를 찾는 소모임, 회사 동료)
- 어디서 알고 오나: 네이버 검색·지도

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격 (1인당)
2. 몇 명까지 가능한지
3. 가능한 날짜·시간

## 4. 믿게 할 증거 (실제로 있는 것만)
- 수업·작품 사진 (실제 사진을 받아 넣는다)
- 강사 경력·자격증 (사용자가 알려 준 내용 그대로 넣는다 — 지금은 (미정))
- 후기: 실제 손님 후기가 있다 (원문을 받아 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 견적 요청
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + 「견적 요청」 버튼
2. 모임 안내 — 1인당 가격 · 최대 인원 · 가능한 날짜·시간 (손님이 궁금한 세 가지)
3. 수업·작품 사진 + 강사 소개(경력·자격증)
4. 후기 자리 (실제 후기를 받아 넣는다. 그전엔 비워 둠)
5. 견적 요청 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 하고 싶은 클래스
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정)
- 최대 인원: (미정)
- 시간: (미정)
- 위치: (미정)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 온라인 결제
- 사진 올리기, 알림 메일 (기본으로 다음에)

## 10. 첫 화면 한 문장 후보
1. 친구·동료와 함께 만드는 하루, 원데이 클래스
2. 우리 모임만을 위한 원데이 클래스, 인원과 클래스만 알려 주세요
3. 이번 모임은 같이 만들어 봐요 — 단체 원데이 클래스 견적 요청

## 11. 다음에 할 것
- 온라인 결제
- 가격·인원·시간·위치가 정해지면 8번과 첫 화면에 채워 넣기
- 실제 후기 원문, 사진, 강사 경력을 받아 넣기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 필요 → Supabase Auth로 회원가입·로그인·회원 전용 페이지, 관리자 화면에 회원 목록 (leaderpl-admin 스킬). 회원 정보를 모으므로 **개인정보 처리방침 페이지가 필요하다.** 견적 요청은 로그인 없이도 남길 수 있게 둔다.
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 견적 요청 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 회원가입·로그인·회원 전용 페이지와 개인정보 처리방침 페이지를 만든다
5. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
